# aws-saa-labs

Labs em Terraform feitos durante o estudo para a **AWS Certified Solutions Architect – Associate (SAA-C03)**.
Um lab por semana, mapeado para os domínios oficiais da prova.

| Semana | Tema | Lab |
|---|---|---|
| 00 | Setup | Provider, default tags, primeiro recurso |
| 01 | IAM / multi-conta | Role, trust policy, instance profile |

> Tudo é criado numa conta de laboratório e destruído no fim da sessão (`terraform destroy`).
